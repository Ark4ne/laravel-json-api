Laravel JSON:API renders your models as [JSON:API 1.1](https://jsonapi.org/format/) documents. A resource **describes**
its members with typed descriptors (`$this->string()`, `$this->one(UserResource::class)`); the package compiles that
description once per class into a **definition**, validates `include` and `fields` against it, loads the relations a
document needs in batch, and renders only what the request asks for.

```php [app/Http/Resources/PostResource.php]
#[JsonApiType('posts')]
final class PostResource extends JsonApiResource
{
    public function toAttributes(Request $request): iterable
    {
        return [
            'title' => $this->string(),
            'published-at' => $this->datetime('published_at'),
        ];
    }

    protected function toRelationships(Request $request): iterable
    {
        return [
            'author' => $this->one(UserResource::class),
            'comments' => $this->many(CommentResource::class),
        ];
    }
}
```

## In this documentation

- **Resources**: the hooks of a resource, its values, conditions, relationships, links and meta.
- **Requests**: includes and sparse fieldsets, their validation, write requests and error documents.
- **API revisions**: how a resource keeps serving the clients pinned on an older revision.
- **Tooling**: `jsonapi:check`, static analysis and deployment.
- **Integrations**: Laravel's native JSON:API resources and OpenAPI.
