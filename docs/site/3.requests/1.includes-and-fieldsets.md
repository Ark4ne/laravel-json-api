---
title: Includes & sparse fieldsets
description: How include and fields shape a document, and the settings that bound them.
---

A client asks for related resources with [`include`](https://jsonapi.org/format/#fetching-includes) and restricts the
fields of each type with [`fields`](https://jsonapi.org/format/#fetching-sparse-fieldsets). Both are read from the
query string only.

::http-call{method="GET" url="/posts/10?include=author,comments.author&fields[posts]=title,author&fields[users]=name"}
::

## Includes

- Each path names relationships, dot-separated: `comments.author` includes the comments and their authors.
- The included resources are loaded before rendering, one query per relation and per include level.
- `include.max-depth` bounds the deepest path accepted and rendered (`null`: no limit).
- A relationship included renders its `data`, whatever its [linkage](/laravel-json-api/resources/relationships#linkage).

## Sparse fieldsets

- `fields[type]` lists the attributes and relationships to render for that type; the others are never computed.
- By default it restricts the relationships too, as the specification says. `fields.relationships` set to `keep`
  renders every relationship whatever `fields` (the behaviour of 1.x).
- A value with `->whenInFields()` is rendered only when `fields[type]` names it explicitly, never by default.
- `fields[users]=address.city` keeps one member of a [struct](/laravel-json-api/resources/attributes#objects).

## Reading them in your code

`Ark4ne\JsonApi\Context\JsonApiContext` holds the include tree and the fieldsets of the current request:

```php
$context = app(JsonApiContext::class);

// true when the path is included
$context->include->has('posts.comments');
// true when `title` of `post` is rendered
$context->fields->allows('post', 'title');
```

In a resource, prefer the [request conditions](/laravel-json-api/resources/conditions#on-the-request):
`whenInFields()` and `whenInIncludes()`.

## Validating them

Without validation, an unknown path is ignored. Validate both against the definitions with a
[`JsonApiFormRequest`](/laravel-json-api/requests/validation).
