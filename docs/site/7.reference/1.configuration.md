---
title: Configuration
description: Every key of config/jsonapi.php.
---

Publish the file with
`php artisan vendor:publish --provider="Ark4ne\JsonApi\Laravel\JsonApiServiceProvider" --tag=config`. It is validated
at boot: a wrong value throws `InvalidConfigurationException` naming the key.

## describer

::field-group
:::field{name="describer.nullable" type="bool"}
Values are nullable unless `->nullable(false)`. Default `true`.
:::
:::field{name="describer.precision" type="int|null"}
Decimals a `float()` is rounded to unless `->precision()` gives one. Default `null`: left as it is.
:::
:::field{name="describer.when-has" type="bool|string[]"}
Applies `whenHas()` automatically: `true`, or the scopes `['attributes', 'resource-meta', 'meta']`. Default `false`.
:::
::

## type

::field-group
:::field{name="type.naming" type="string|class-string"}
The type of a resource without `toType()` nor `#[JsonApiType]`: `kebab-singular` (default), `kebab-plural`,
`snake-plural`, or a class implementing `Ark4ne\JsonApi\Configuration\TypeNaming`.
:::
::

## relationship

::field-group
:::field{name="relationship.linkage" type="'always'|'loaded'|'included'"}
When a relationship that is not included renders its `data`. Default `always`. See
[Linkage](/laravel-json-api/resources/relationships#linkage).
:::
::

## fields

::field-group
:::field{name="fields.relationships" type="'filter'|'keep'"}
`fields[type]` restricts the relationships too (`filter`, the specification) or not (`keep`, the behaviour of 1.x).
Default `filter`.
:::
::

## include

::field-group
:::field{name="include.max-depth" type="int|null"}
Deepest include path accepted; nothing deeper is loaded nor rendered. Default `null`: no limit.
:::
::

## definitions

::field-group
:::field{name="definitions.paths" type="string[]"}
Where `jsonapi:cache` and `jsonapi:check` look for resources. Default `[]`: the `app` directory.
:::
::

## rendering

::field-group
:::field{name="rendering.stages" type="class-string[]"}
`Ark4ne\JsonApi\Rendering\Stage` classes run after those of the package, for every resource object. Default `[]`.
:::
::

## errors

::field-group
:::field{name="errors.renderers" type="class-string[]"}
`Ark4ne\JsonApi\Http\Errors\ErrorRenderer` classes of the application. Default `[]`. See
[Errors](/laravel-json-api/requests/errors#error-renderers-of-your-own).
:::
::

## document

::field-group
:::field{name="document.jsonapi" type="array|false"}
The top-level `jsonapi` member: `version` (`1.1`), `ext`, `profile`, `meta`. `false` leaves it out. Its `ext` are the
extensions accepted by the content negotiation.
:::
::

## Set in config/revisions.php

The format of a date and time (`date_time_format`), the strictness of the values (`strict_values`) and the revisions
(`enum`, `resolvers`) belong to `ark4ne/laravel-api-revisions`. The keys `describer.datetime`, `describer.strict` and
`describer.types` of 2.x are refused.
