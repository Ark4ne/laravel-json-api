---
title: Commands
description: The Artisan commands of the package.
---

| Command | Effect |
| --- | --- |
| `php artisan make:jsonapi-resource PostResource [--model=Post] [--force]` | Writes a resource from the casts, fillable attributes and relations of the model |
| `php artisan jsonapi:check [resources…] [--strict] [--revision=Case]` | Prints the findings about the resources at every revision; fails on an error, on a warning too with `--strict` |
| `php artisan jsonapi:cache` | Compiles every definition into `bootstrap/cache/jsonapi.php` (run by `optimize`) |
| `php artisan jsonapi:clear` | Removes the compiled definitions (run by `optimize:clear`) |

`php artisan revision:check`, `revision:lock` and `revision:cache` belong to
[`ark4ne/laravel-api-revisions`](/laravel-api-revisions).
